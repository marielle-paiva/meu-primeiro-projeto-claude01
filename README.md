# meu-primeiro-projeto-claude01

Repositório inicial para aprender a criar aplicações com o [Claude Code](https://claude.com/claude-code).

## Como trabalhar neste repositório

1. Abra uma sessão do Claude Code com este repositório selecionado.
2. Descreva em português o que você quer criar (ex.: "crie uma página de lista de tarefas").
3. Peça para o Claude **explicar** o que fez e **rodar** o resultado.
4. Quando estiver bom, peça: "faça commit e push".

## Estrutura

```
.
├── CLAUDE.md      # Instruções que o Claude lê em toda sessão
├── README.md      # Este arquivo
├── docs/          # Anotações, ideias e aprendizados
└── src/           # Código da aplicação
```

## Ideias de primeiros projetos

- [ ] Página pessoal (HTML + CSS)
- [ ] Lista de tarefas (JavaScript)
- [ ] Calculadora simples
- [ ] Script que lê uma planilha CSV e gera um resumo (Python)
