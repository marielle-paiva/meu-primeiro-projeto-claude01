# CLAUDE.md

Instruções para o Claude Code neste repositório.

## Sobre mim
- Estou aprendendo a programar com o Claude Code; explique as decisões de forma simples.
- Responda sempre em português.

## Como trabalhar
- Antes de mudanças grandes, mostre um plano curto e espere meu ok.
- Prefira soluções simples e com poucas dependências.
- Coloque o código em `src/` e anotações em `docs/`.
- Depois de mudar algo, rode o projeto ou os testes e me diga o resultado.

## Git
- Trabalhe em uma branch nova para cada funcionalidade (ex.: `feat/lista-de-tarefas`).
- Mensagens de commit curtas em português, no imperativo (ex.: "Adiciona página inicial").
- Nunca coloque senhas, tokens ou chaves de API no código; use um arquivo `.env` (já ignorado pelo git).
